# コードで育つペット — Code-Grown Pet

VS Codeでコードを書いて保存すると、卵から生まれた小さな相棒が育つデスクトップ育成ゲームです。

[English README](README.md) | [アーキテクチャ設計](ARCHITECTURE.ja.md)

## コンセプト

いつものコーディングに、小さな育成の楽しみを加えます。最初にもらった卵が日々の作業で少しずつ変化し、孵化して、生き物へと成長します。

キャラクターは画面右下の小さな透明ウィンドウに表示します。エディターの表示領域を確保したまま、クリックは背後のアプリへ通し、作業を邪魔しない相棒を目指します。

## 現在の状態

**企画段階です。** 現時点ではドキュメントのみで、動作するアプリはありません。以下は実装済みの機能ではなく、目指す体験と設計案です。実行可能な試作品ができた段階で、導入・使用手順を追加します。

## 目指す体験

- 初回利用時に卵をもらう。
- VS Codeでコードを書いて保存すると、成長ポイントがたまる。
- 卵にひびが入り、孵化し、相棒が成長する。
- 普段はゆっくり揺れ、保存時には短いリアクションをする。
- アプリを閉じても、次回は同じ相棒と成長状態から再開する。
- ショートカットで表示・非表示を切り替え、タスクトレイから終了できる。
- 休んでも弱らない。自分のペースで育てられる。

最初の対応OSはWindowsです。VS Codeのパネルを占有しない表示方法を採用する予定です。

## 検討中の成長ルール

保存するたびにファイル全体の文字数を加算するのではなく、前回の保存からの変更を成長に反映します。

- 変更のない保存ではポイントを加算しない。
- 追加・書き換えた文字を成長に反映する。
- 自動保存にも対応し、リアクションはまとめるか頻度を制限する。
- 削除やリファクタリングも考慮し、コードを増やすことだけが成長につながる仕組みにしない。

具体的な文字数の計算方法、成長に必要なポイント、生成ファイルの扱い、操作の取り消しへの対応は未決定です。文字数は遊びのための指標であり、生産性やコード品質を評価するものではありません。

成長段階の例：

`卵 → ひびの入った卵 → 幼体 → 成体`

最初の生き物や絵柄は、これから決めます。

## 構成案

| 構成要素 | 役割 |
| --- | --- |
| Electron補助アプリ | 透明表示・演出・成長判定・育成状態の保存・トレイ操作を担当する。 |
| VS Code拡張機能 | 補助アプリの開始・停止、保存検知、変更量の計測と通知を担当する。 |
| 共有プロトコル | ローカル通信の型と検証を共有する。育成状態の保存はElectron側に集約する。 |

最初のWindows用試作品にはElectronとTypeScriptを採用し、ローカルのHTML/CSSと自作SVGの卵を表示します。開発者がJavaScriptより慣れているため、最初からTypeScriptを使用します。将来の保存検知にはVS Codeの `workspace.onDidSaveTextDocument` を利用できます。技術選定は試作品で検証していきます。

コードの内容はVS Code内で扱い、ローカルのキャラクターアプリには成長に必要な情報だけを送る設計を想定しています。構成案ではクラウドサービスを必要としません。

最初の試作品は、他のアプリの上にも表示される可能性があります。「VS Codeが手前にあるときだけ表示する」「VS Codeのウィンドウに追従する」は、Windows側の追加連携が必要な将来の改善候補です。

- [ ] M0：拡張から補助アプリを開始・停止し、静止した卵の表示・クリック透過・トレイ終了・接続断での終了を作る。
- [ ] M1：ゆっくり揺れるアニメーションと表示切り替えショートカットを追加する。
- [ ] 最小限のVS Code拡張機能で保存を検知する。
- [ ] 変更量の計算ルールを決め、保存イベントと成長をつなぐ。
- [ ] 成長状態の保存、孵化、成長段階を実装する。
- [ ] 日常作業に合わせて、演出・アクセシビリティ・リソース使用量を調整する。
- [ ] VS Codeへのウィンドウ追従や、新しい生き物を検討する。
